1b:T336a,<p>Solvix options are grouped into two levels:</p>
<ol>
<li><strong>Global options</strong> — passed to <code>createClient({...})</code>, apply to every request</li>
<li><strong>Per-request options</strong> — passed to <code>client.get(url, {...})</code>, override globals for a single request</li>
</ol>
<p>Both use the same <code>SolvixOptions</code> interface. Every field is optional.</p>
