<h2 id="best-practices">Best Practices</h2>
<ol>
<li><strong>Create one group per page/screen</strong> — allows clean cancellation on navigation</li>
<li><strong>Always abort old groups</strong> — prevents stale data from populating new views</li>
<li><strong>Monitor stats</strong> — track group duration to measure page load performance</li>
<li><strong>Groups are lightweight</strong> — create and discard them freely</li>
</ol>
