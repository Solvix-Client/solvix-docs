<h2 id="request-batching">Request Batching</h2>
<p>Batch multiple GraphQL operations into a single HTTP request. Operations are collected and sent together after a configurable interval or when the batch is full.</p>

<span data-line=""><span style="color:#ADBAC7">  batching: {</span></span>

<span data-line=""><span style="color:#ADBAC7">    maxBatchSize: </span><span style="color:#6CB6FF">10</span><span style="color:#ADBAC7">,     </span><span style="color:#768390">// Max operations per batch (default: 10)</span></span>
<span data-line=""><span style="color:#ADBAC7">    batchInterval: </span><span style="color:#6CB6FF">10</span><span style="color:#ADBAC7">,    </span><span style="color:#768390">// Wait time in ms before sending (default: 10)</span></span>

<h2 id="automatic-persisted-queries-apq">Automatic Persisted Queries (APQ)</h2>
<p>APQ reduces bandwidth by sending a SHA-256 hash of the query instead of the full query string. The server caches the hash-to-query mapping.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F47067">const</span><span style="color:#6CB6FF"> graphql</span><span style="color:#F47067"> =</span><span style="color:#DCBDFB"> createGraphQLClient</span><span style="color:#ADBAC7">(client, {</span></span>
<span data-line=""><span style="color:#ADBAC7">  endpoint: </span><span style="color:#96D0FF">"/graphql"</span><span style="color:#ADBAC7">,</span></span>
<span data-line=""><span style="color:#ADBAC7">  persistedQueries: { enabled: </span><span style="color:#6CB6FF">true</span><span style="color:#ADBAC7"> },</span></span>
<span data-line=""><span style="color:#ADBAC7">  defaultMethod: </span><span style="color:#96D0FF">"GET"</span><span style="color:#ADBAC7">,  </span><span style="color:#768390">// APQ works best with GET (CDN caching)</span></span>
<span data-line=""><span style="color:#ADBAC7">});</span></span>
<span data-line=""> </span>
<span data-line=""><span style="color:#768390">// First request: sends hash only, server responds with PERSISTED_QUERY_NOT_FOUND</span></span>
<span data-line=""><span style="color:#768390">// Second request: sends hash + full query, server caches it</span></span>
<span data-line=""><span style="color:#768390">// All subsequent requests: sends hash only (smaller payload)</span></span>
<span data-line=""><span style="color:#F47067">const</span><span style="color:#ADBAC7"> { </span><span style="color:#6CB6FF">data</span><span style="color:#ADBAC7"> } </span><span style="color:#F47067">=</span><span style="color:#F47067"> await</span><span style="color:#ADBAC7"> graphql.</span><span style="color:#DCBDFB">query</span><span style="color:#ADBAC7">(</span><span style="color:#96D0FF">`{ users { id name } }`</span><span style="color:#ADBAC7">);</span></span></code></pre></figure>
<h2 id="entity-level-cache-normalization">Entity-level Cache Normalization</h2>
<p>The normalized cache extracts entities from GraphQL responses using <code>__typename</code> and <code>id</code> fields, stores them with TTL, and can reconstruct responses from cached entities.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F47067">const</span><span style="color:#6CB6FF"> graphql</span><span style="color:#F47067"> =</span><span style="color:#DCBDFB"> createGraphQLClient</span><span style="color:#ADBAC7">(client, {</span></span>

<span data-line=""><span style="color:#ADBAC7">    enabled: </span><span style="color:#6CB6FF">true</span><span style="color:#ADBAC7">,</span></span>
<span data-line=""><span style="color:#ADBAC7">    keyFields: [</span><span style="color:#96D0FF">"__typename"</span><span style="color:#ADBAC7">, </span><span style="color:#96D0FF">"id"</span><span style="color:#ADBAC7">],  </span><span style="color:#768390">// Default entity key fields</span></span>
<span data-line=""><span style="color:#ADBAC7">    ttl: </span><span style="color:#6CB6FF">300000</span><span style="color:#ADBAC7">,                       </span><span style="color:#768390">// 5 minutes (default)</span></span>
<span data-line=""><span style="color:#ADBAC7">  },</span></span>
<span data-line=""><span style="color:#ADBAC7">});</span></span>
<span data-line=""> </span>

<span data-line=""><span style="color:#ADBAC7">  cacheNormalization: {</span></span>
