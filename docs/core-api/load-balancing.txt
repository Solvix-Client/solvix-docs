<h2 id="built-in-strategies">Built-in Strategies</h2>
<h3 id="round-robin">Round-robin</h3>
<p>Distributes requests evenly across all backends in order.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F47067">const</span><span style="color:#6CB6FF"> transport</span><span style="color:#F47067"> =</span><span style="color:#DCBDFB"> createLoadBalancer</span><span style="color:#ADBAC7">({</span></span>
<span data-line=""><span style="color:#ADBAC7">  backends: [</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-1.example.com"</span><span style="color:#ADBAC7"> },</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-2.example.com"</span><span style="color:#ADBAC7"> },</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-3.example.com"</span><span style="color:#ADBAC7"> },</span></span>
<span data-line=""><span style="color:#ADBAC7">  ],</span></span>
<span data-line=""><span style="color:#ADBAC7">  strategy: </span><span style="color:#96D0FF">"round-robin"</span><span style="color:#ADBAC7">,  </span><span style="color:#768390">// Default</span></span>
<span data-line=""><span style="color:#ADBAC7">});</span></span></code></pre></figure>
<h3 id="random">Random</h3>
<p>Picks a random backend for each request.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">strategy</span><span style="color:#ADBAC7">: </span><span style="color:#96D0FF">"random"</span></span></code></pre></figure>
<h3 id="weighted">Weighted</h3>
<p>Distributes traffic proportionally based on <code>weight</code>. A backend with <code>weight: 3</code> receives roughly 3x the traffic of one with <code>weight: 1</code>.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F47067">const</span><span style="color:#6CB6FF"> transport</span><span style="color:#F47067"> =</span><span style="color:#DCBDFB"> createLoadBalancer</span><span style="color:#ADBAC7">({</span></span>
<span data-line=""><span style="color:#ADBAC7">  backends: [</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-1.example.com"</span><span style="color:#ADBAC7">, weight: </span><span style="color:#6CB6FF">5</span><span style="color:#ADBAC7"> },  </span><span style="color:#768390">// 50% of traffic</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-2.example.com"</span><span style="color:#ADBAC7">, weight: </span><span style="color:#6CB6FF">3</span><span style="color:#ADBAC7"> },  </span><span style="color:#768390">// 30% of traffic</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-3.example.com"</span><span style="color:#ADBAC7">, weight: </span><span style="color:#6CB6FF">2</span><span style="color:#ADBAC7"> },  </span><span style="color:#768390">// 20% of traffic</span></span>
<span data-line=""><span style="color:#ADBAC7">  ],</span></span>
<span data-line=""><span style="color:#ADBAC7">  strategy: </span><span style="color:#96D0FF">"weighted"</span><span style="color:#ADBAC7">,</span></span>
<span data-line=""><span style="color:#ADBAC7">});</span></span></code></pre></figure>
<h3 id="health">Health</h3>
<p>Same as round-robin but filters to healthy backends first. Falls back to all backends if none are healthy (circuit-breaker style).</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#F69D50">strategy</span><span style="color:#ADBAC7">: </span><span style="color:#96D0FF">"health"</span></span></code></pre></figure>

<p>For full control, pass a function that receives the backend pool and returns the selected backend.</p>

<span data-line=""><span style="color:#ADBAC7">  backends: [</span></span>
<span data-line=""><span style="color:#ADBAC7">    { url: </span><span style="color:#96D0FF">"https://api-1.example.com"</span><span style="color:#ADBAC7"> },</span></span>
