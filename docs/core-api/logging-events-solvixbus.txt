<h2 id="best-practices">Best Practices</h2>
<ol>
<li><strong>Subscribe once at app boot</strong> — SolvixBus is a singleton, subscribe in your app setup code</li>
<li><strong>Don't mutate the event context</strong> — it's a snapshot; use middleware or hooks for modifications</li>
<li><strong>Keep listeners fast</strong> — they run synchronously; slow listeners delay the event loop</li>
<li><strong>Handle errors in listeners</strong> — SolvixBus catches errors, but you won't see them without your own try/catch</li>
</ol>
