<h2 id="best-practices">Best Practices</h2>
<ol>
<li><strong>Set <code>timeout: 0</code> for long-lived SSE connections</strong> — prevents unwanted disconnection</li>
<li><strong>Handle stream errors gracefully</strong> — connections drop, implement reconnection logic</li>
<li><strong>Use <code>sse: true</code> for standard SSE endpoints</strong> — handles EventSource format automatically</li>
<li><strong>Buffer partial lines</strong> — NDJSON chunks may split in the middle of a line</li>
<li><strong>Cancel streams with <code>ReadableStream.cancel()</code></strong> — clean up when done</li>
</ol>
