Request Options Reference

This is the complete reference for all SolvixOptions fields. Every option can be set globally in createClient() and overridden per-request.

Core Options

baseURL

string — Base URL prepended to all relative request URLs.

timeout

number (ms) — Request timeout. Uses AbortController internally.

method

HttpMethod — HTTP method. Auto-set by .get(), .post(), etc.

headers

Record<string, string> — Default headers for every request.

params

Record<string, any> — Query parameters merged into the URL.

paramsSerializer

(params: Record<string, any>) => string — Custom query parameter serializer.

body

unknown — Request body. Serialized according to bodyType.

bodyType

"json" | "form" | "multipart" | "text" | "blob" | "arrayBuffer" | "raw" — How to serialize the body.

responseType

"json" | "text" | "blob" | "arrayBuffer" | "formData" | "stream" | "raw" — How to parse the response.

stream

boolean — Enable response streaming as an async iterable.

sse

boolean — Parse Server-Sent Events from the response stream.

parseJsonLines

boolean — Parse NDJSON (newline-delimited JSON).

validateStatus

(status: number) => boolean — Custom status validation.

validateResponse

(data: unknown) => any — Response schema validation. Compatible with Zod, Valibot.

fetch

RequestInit — Raw fetch options (credentials, mode, redirect, etc.).

Resilience Options

retry

number | RetryOptions — Automatic retry configuration.

Full retry documentation →

circuitBreaker

CircuitBreakerOptions — Per-host circuit breaker.

Full circuit breaker documentation →

rateLimit

RateLimitOptions — Token bucket rate limiter.

Full rate limiting documentation →

dedupe

boolean — Deduplicate in-flight requests.

Full dedup documentation →

cache

boolean | CacheOptions — In-memory response caching.

maxConcurrency

number — Maximum concurrent requests. Default: Infinity.

priority

number — Queue priority (lower = higher). Default: 5.

queue

QueueOptions — Queue behavior configuration.

fallbackURLs

string[] — Backup URLs tried when primary fails.

fingerprint

FingerprintOptions — Customize cache/dedup key fingerprinting.

Security Options

security

SolvixSecurityOptions — Multi-layer security configuration.

Full security documentation →

csrf

CSRFOptions — CSRF token injection from cookie to header.

tls

TLSOptions — TLS/SSL configuration (Node.js, requires undici).

proxy

ProxyOptions — HTTP proxy configuration (Node.js, requires undici).

allowedOrigins

string[] — Allowed CORS origins (browser).

avoidPreflight

boolean — Keep requests simple to avoid CORS preflight.

Observability Options

timeline

TimelineOptions — 15-stage request timeline.

profiling

ProfilingOptions — Performance profiling summary.

logger

SolvixLogger — Structured logger interface. Compatible with console, pino, winston.

correlation

CorrelationOptions — Auto-assign X-Request-ID header.

metrics

MetricsOptions — Aggregated request metrics.

tracing

TracingOptions — W3C Trace Context propagation.

healthCheck

HealthCheckOptions — Periodic endpoint health pinging.

snapshot

SnapshotOptions — Capture full request snapshot for debugging.

devMode

boolean — Development-mode warnings for misconfigurations.

Auth Options

auth

AuthOptions — Automatic token refresh (stampede-safe).

cookieJar

CookieJarOptions — In-memory cookie storage.

etag

ETagOptions — Conditional GET support.

Advanced Options

hooks

SolvixHooks — Lifecycle callbacks.

Full hooks documentation →

transport

SolvixTransport — Custom transport function.

transformRequest

(body, headers) => any — Transform body and headers before sending.

transformResponse

(response) => any — Transform the raw Response after receiving.

group

RequestGroup — Attach to a group for batch abort.

id and dependsOn

string and string[] — Dependency chain support.

shadow

ShadowOptions — Shadow requests to secondary API.

offline

OfflineOptions — Offline request queuing (browser).
