1c:T1764,<h2 id="v100-2026-06-23--stable-release">v1.0.0 (2026-06-23) — Stable Release</h2>
<h3 id="whats-new-since-beta">What's New Since Beta</h3>
<p>Solvix 1.0.0 adds <strong>16 new features</strong> and <strong>6 performance optimizations</strong> on top of the beta foundation, bringing the total to <strong>~50 built-in features</strong>.</p>
<h4 id="security-3-new">Security (3 new)</h4>
<ul>
<li><strong>CSRF Protection</strong> — reads <code>XSRF-TOKEN</code> cookie, injects <code>X-XSRF-TOKEN</code> header on state-changing methods (POST/PUT/PATCH/DELETE). Customizable cookie name and header name.</li>
<li><strong>TLS/SSL Configuration</strong> — <code>rejectUnauthorized</code>, custom CA, client cert/key for mTLS. Uses <code>undici</code> Agent (Node.js, optional dependency).</li>
<li><strong>HTTP/HTTPS Proxy</strong> — <code>proxy: { host, port, auth }</code> for corporate networks. Uses <code>undici ProxyAgent</code>.</li>
</ul>
<h4 id="resilience-3-new">Resilience (3 new)</h4>
<ul>
<li><strong>Health Checks</strong> — <code>client.healthCheck</code> with interval-based endpoint pinging, <code>onStatusChange</code> callback, <code>health:change</code> events.</li>
<li><strong>Cookie Management</strong> — in-memory <code>CookieJar</code> for Node.js/edge. Parses <code>Set-Cookie</code>, attaches <code>Cookie</code> on subsequent requests.</li>
<li><strong>User-Extensible Middleware</strong> — <code>client.use(middleware)</code> for injecting custom Koa-style middleware into the request pipeline.</li>
</ul>
<h4 id="observability-4-new">Observability (4 new)</h4>
<ul>
<li><strong>Correlation IDs</strong> — auto <code>X-Request-ID</code> header on every request, stored in <code>ctx.meta</code>, included in all log metadata.</li>
<li><strong>Aggregated Metrics</strong> — <code>client.metrics()</code> returns total/active/success/failure/retry counters + duration histogram (configurable buckets).</li>
<li><strong>Distributed Tracing</strong> — W3C <code>traceparent</code> header injection (format <code>00-{traceId}-{spanId}-01</code>), same traceId across retries, new spanId per attempt.</li>
<li><strong>Public Event Bus</strong> — <code>SolvixBus</code> exported for external subscriptions to <code>request:start</code>, <code>:complete</code>, <code>:error</code>, <code>:retry</code>, <code>health:change</code>, shadow events.</li>
</ul>
<h4 id="data-handling-2-new">Data Handling (2 new)</h4>
<ul>
<li><strong>Progress Events</strong> — <code>onUploadProgress</code> and <code>onDownloadProgress</code> hooks via ReadableStream counting. Works with Blob, string, ArrayBuffer bodies.</li>
<li><strong>Response Schema Validation</strong> — <code>validateResponse</code> callback (compatible with Zod, Valibot, or custom functions). Zero external dependencies.</li>
</ul>
<h4 id="caching--routing-2-new">Caching &#x26; Routing (2 new)</h4>
<ul>
<li><strong>Graceful Fallback URLs</strong> — <code>fallbackURLs[]</code> tried automatically when primary URL fails with retryable errors.</li>
<li><strong>Custom paramsSerializer</strong> — full control over query parameter serialization format (bracket notation, indexed, etc.).</li>
</ul>
