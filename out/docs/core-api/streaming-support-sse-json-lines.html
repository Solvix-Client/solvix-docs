Best Practices

  1. Set timeout: 0 for long-lived SSE connections — prevents unwanted disconnection
  2. Handle stream errors gracefully — connections drop, implement reconnection logic
  3. Use sse: true for standard SSE endpoints — handles EventSource format automatically
  4. Buffer partial lines — NDJSON chunks may split in the middle of a line
  5. Cancel streams with ReadableStream.cancel() — clean up when done
