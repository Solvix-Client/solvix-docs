<h2 id="core-options">Core Options</h2>
<h3 id="baseurl"><code>baseURL</code></h3>
<blockquote>
<p><code>string</code> — Base URL prepended to all relative request URLs.</p>
</blockquote>

<h3 id="timeout"><code>timeout</code></h3>
<blockquote>
<p><code>number</code> (ms) — Request timeout. Uses AbortController internally.</p>
</blockquote>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#22272e;color:#adbac7" tabindex="0" data-language="ts" data-theme="github-dark-dimmed"><code data-language="ts" data-theme="github-dark-dimmed" style="display: grid;"><span data-line=""><span style="color:#ADBAC7">client.</span><span style="color:#DCBDFB">get</span><span style="color:#ADBAC7">(</span><span style="color:#96D0FF">"/slow"</span><span style="color:#ADBAC7">, { timeout: </span><span style="color:#6CB6FF">30000</span><span style="color:#ADBAC7"> }); </span><span style="color:#768390">// 30 seconds</span></span></code></pre></figure>

<blockquote>
<p><code>HttpMethod</code> — HTTP method. Auto-set by <code>.get()</code>, <code>.post()</code>, etc.</p>
