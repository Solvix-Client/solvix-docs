---
title: TLS/SSL Configuration
description: Custom TLS settings for Node.js — self-signed certificates, mTLS, and custom CA bundles. Requires undici.
---

```ts
import { createClient } from "@adityadev13/solvix";

const client = createClient({
  baseURL: "https://internal.example.com",
  tls: {
    rejectUnauthorized: false, // Accept self-signed certs
  },
});

await client.get("/data"); // TLS errors are ignored
```

## Configuration

```ts
interface TLSOptions {
  rejectUnauthorized?: boolean;    // Reject self-signed certs. Default: true
  ca?: string | string[];          // Custom CA certificate(s)
  cert?: string;                   // Client certificate (mTLS)
  key?: string;                    // Client key (mTLS)
  servername?: string;             // SNI override
}
```

## mTLS (Mutual TLS)

```ts
const client = createClient({
  tls: {
    ca: fs.readFileSync("ca.pem", "utf-8"),
    cert: fs.readFileSync("client.crt", "utf-8"),
    key: fs.readFileSync("client.key", "utf-8"),
  },
});
```

## Requirements

- Node.js 18+
- `undici` package installed (`npm install undici`)
- Feature is automatically disabled when `undici` is not available
