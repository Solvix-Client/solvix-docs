```ts
import { createClient } from "@adityadev13/solvix";

const client = createClient({
  tracing: { enabled: true },
});

await client.get("/users");
// Request header: traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
```

## How It Works

Each request generates a W3C `traceparent` header in the format:

```
00-{traceId}-{spanId}-01
```

- **traceId** — same across all retries of the same request
- **spanId** — new for each attempt (retries get a new span)
- **01** — trusted trace flag

The `traceId` is also available in `res.meta.traceId` for correlation with your tracing backend.

## Use With OpenTelemetry

The `traceparent` header is compatible with OpenTelemetry and any W3C Trace Context-aware system:
- Datadog
- Jaeger
- Zipkin
- AWS X-Ray
- Grafana Tempo
