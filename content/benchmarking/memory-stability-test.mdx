title: Memory Stability Test
description: Validates no memory leaks across 30,000 requests. Memory stabilizes after initial warm-up.
---

```bash
# Run: npx tsx --expose-gc bench/memory.bench.ts
```

## Results

| Round | Start Heap | End Heap | Growth |
|-------|-----------|---------|--------|
| Round 1 | 6.69 MB | 8.79 MB | +2.11 MB |
| Round 2 | 8.78 MB | 8.83 MB | +0.05 MB |
| Round 3 | 8.76 MB | 8.81 MB | +0.06 MB |

**10,000 requests per round, 3 rounds.**

## Analysis

- Initial growth (Round 1) is cold-start allocation — V8 heap expansion, module loading, internal data structures
- Rounds 2 and 3 show **near-zero growth** — memory stabilizes and stays flat
- No incremental growth pattern — no leak

## Conclusion

Solvix demonstrates stable memory behavior suitable for long-running processes.
